# HH Auto Search

Скрипт для Tampermonkey, который автоматически открывает вакансии на hh.ru по одной, засчитывает просмотр и закрывает вкладку.

## Требования

- Браузер Opera / Chrome / Firefox (создавался для браузера Opera и тестировался в нем же)
- Расширение [Tampermonkey](https://www.tampermonkey.net/)

## Установка

1. Установить расширение Tampermonkey
2. Открыть панель Tampermonkey → **Создать новый скрипт**
3. Вставить содержимое файла `hh-auto-search.user.js`
4. Сохранить (`Ctrl+S`)

## Использование

1. Перейти на страницу поиска вакансий:
https://hh.ru/search/vacancy
2. В правом верхнем углу появится панель управления
3. Указать цель — сколько вакансий открыть (или оставить пустым для режима без лимита)
4. Нажать **Старт**

## Как работает

- Каждая вакансия открывается в фоновой вкладке
- Через 2 секунды вкладка закрывается автоматически
- Просмотр засчитывается, так как страница успевает загрузиться
- При достижении цели скрипт останавливается сам
- При окончании страницы автоматически переходит на следующую

## Настройки в коде

| Время пребывания на новой вкладке | `const DELAY_MS` | `2000` мс |
| Пауза между вакансиями | `const PAUSE_BETWEEN` | `700` мс |
| Цель по умолчанию | `value="..."` в поле input |
